# 排障指南

先跑 `node scripts/setup.mjs --doctor`，按下面四段解读输出。

## doctor 四段的含义与退出码

1. **文件与配置检查**：脚本可直接验证的部分——Node ≥ 22、Python 3 是否可用、安装清单与各目标是否存在且与安装时一致、Hook 五个事件是否都有本包条目、`ZCODE_CALLBACK_BRIDGE_RECONCILE` 的设置状态。以下任一情况 doctor 退出码非 0：Node/Python 缺失或版本不足、安装清单缺失/损坏、目标缺失或被修改、Hook 配置缺失/损坏、对账变量已设置但指向不存在的文件。变量**未设置**不是失败——对账命令可用内联前缀（见下），doctor 会打印可复制的命令。
2. **宿主实际加载：未验证**：安装器无法证明 ZCode/Codex 宿主真的加载了技能或 Hook。请打开两端客户端确认技能列表可见；宿主首次触发 Hook 时会请求你审查并信任，由你在客户端中批准，本安装器不修改信任记录。
3. **系统权限：待人工确认**：macOS 辅助功能/自动化权限只能由你在「系统设置 → 隐私与安全性」中人工授予；脚本既不能授予也不能证明已授予。
4. **端到端回传：未验证**：只有完成一次真实派发→执行→回传→验收闭环才能证明回传可用。doctor 永远不会替你宣称“权限已授予”或“回传成功”。

## 安装被拒绝

| 提示 | 原因 | 下一步 |
| --- | --- | --- |
| 目标已存在但不属于本包 | 该路径有文件但安装清单无记录 | 人工确认内容后移走它 |
| 目标内容与安装清单不符 | 你修改过本包安装的文件 | 先备份/确认你的改动，再手动处理 |
| Hook 配置无法解析 / 结构无法识别 | hooks.json 损坏或不是预期形状 | 先人工修复该文件再重跑 |
| 本包 guard 条目已被修改 | 条目存在但与标准不一致 | 人工清理为一致或删除该条后重跑 |
| 目标路径包含符号链接 | HOME/CODEX_HOME 以下通往目标的环节上有链接 | 改用真实目录；本包不提供任意自定义路径选项 |
| 目标不在锚点之下 / 重叠 / 位于 zcode-runs 内 | 统一路径边界检查 | 不会发生在外部输入下；出现即报告 |
| 计划已过期 | 确认窗口内目标出现/变化 | 查看新打印的计划后重新确认 |

被拒绝或计划过期时不会写入任何文件。

## 缺 Node / Python / 版本不足

doctor 按前提表判定：Node < 22 或 python3 不可用都会失败退出。安装器不会自动下载依赖，也不使用 sudo——请自行安装后重跑 `--doctor`。

## 宿主没有加载技能 / Hook

- 技能目录：确认两端目录分别对应 ZCode（回传桥）与 Codex（编排技能），且客户端已重启/刷新技能列表。
- Hook 未生效：确认你的宿主读取的是**用户级** `$CODEX_HOME/hooks.json`（默认 `~/.codex/hooks.json`，与 config.toml 并列），而不是插件内部的 `hooks/hooks.json`。宿主首次触发 Hook 会请求信任审批，请在客户端批准。宿主必须提供 `session_id`、`hook_event_name`、`tool_name`、`tool_input`（及 PostToolUse 的 `tool_response`）并执行 guard 的拒绝决定，否则互斥不生效；先在隔离环境跑 `tests/guard` 的 Python 测试再验证真实接线。

## 权限相关

- Computer Use 回传失败、无法控制窗口时，先到「系统设置 → 隐私与安全性 → 辅助功能 / 自动化」人工确认相关应用已获授权，再重试。
- doctor 对权限只报“待人工确认”，不会显示“已授予”。

## 回传未达 / 不确定是否发送

- 本包的回传是有界重试 + 显式证据，不承诺 exactly-once；不确定是否发送过时先只读核验目标任务的完整四行消息，绝不盲目重发。
- 找不到回传锚点、输入框有你的草稿时，worker 会记录阻塞并在预算内有界重试；不会循环打扰，也没有后台自唤醒——会话结束后一切等待下一次显式授权。

## receiver 仍 active / writer 失联

公开协调端没有强制终止 active writer 的命令。保持 checkpoint，等待或按你的部署具备的恢复工具处理；不要猜命令、不要手改账本/receipt/锁、不要删除状态目录来“重置”。

## 免费额度问题

免费额度以平台实际提供及你的账户资格为准；本项目不承诺永久免费、不绕过限制、也不提供未经证实的节省比例。
